### Weapon Manager Flow
```
Left Click -> WeaponManager.start_firing()
  -> _try_fire() -> check ammo -> create projectile -> reduce ammo
  -> emit weapon_fired signal

Q / R -> WeaponManager.switch_weapon(+1 / -1)
  -> emit weapon_switched signal
  -> HUD updates
```

### Loot Flow
```
Enemy dies -> LootSystem.spawn_enemy_loot(position)
  -> Random from loot_table (drop_chance check)
  -> Create pickup Area3D in world

Player touches pickup -> _on_pickup_body_entered(body)
  -> weapon type -> WeaponManager.add_weapon(weapon)
  -> ammo type -> WeaponManager.add_ammo(amount)
  -> repair type -> Erase part_damage for random slot
```

### Salvage Flow
```
Combat ends -> SalvageUI.show_weapons(weapons)
  -> Player tags weapons to keep
  -> Confirm -> SalvageSystem.salvage_all()
  -> Weapons saved to GlobalData for next run
```
